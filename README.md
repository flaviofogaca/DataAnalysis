- **Previsão cancelamento plataforma Streaming**: Criado um modelo de classificação para mapear qual o perfil de usuários tem mais chance de deixar sua plataforma de streaming. Compreender qual é o perfil que está aumentando o ***churn*** do negócio é essencial para tomar ações que reduzam essas perdas, seja alterando critérios na venda ou modificando o produto.

*Churn (ou churn rate) é o termo usado pra representar a taxa de cancelamento de clientes.*

- **Análise Exploratória – Desempenho no ENEM 2023**: Este projeto tem como objetivo explorar os dados do ENEM 2023 para identificar padrões de desempenho dos estudantes a partir de variáveis como idade, sexo, raça, renda familiar e tipo de escola.

  **Principais colunas analisadas:**
- **TP_SEXO**: Sexo do participante  
- **TP_COR_RACA**: Raça/cor autodeclarada  
- **TP_ESCOLA**: Tipo de escola (pública ou privada)  
- **Q006 / RENDA**: Faixa de renda familiar  
- **NOTA_MEDIA**: Média das quatro provas objetivas

Dados como `Q006` foram convertidos em faixas de renda compreensíveis.
Algumas colunas foram renomeadas para facilitar a leitura (ex: `NOTA_MEDIA`, `COR_RACA`, `TIPO_ESCOLA`).
